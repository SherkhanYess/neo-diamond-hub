# Коды профиля: ссылки WhatsApp для bio и сторис

Ссылка ведёт сразу в чат, минуя сайт. Код в конце сообщения инфоцентр
распознаёт как конвертер «Профиль». Источник — Instagram, размещение — bio или
сторис. Если человек сотрёт код, обращение попадёт в «WhatsApp без источника».

Ссылки на сайт из bio и сторис делаются в админке taena («Ссылки»). Это
конвертер «Сайт»: на сайте свой код.

| Код | Бренд | Размещение |
|---|---|---|
| `[N·ib]` | Neo Diamond | bio (шапка профиля) |
| `[N·is]` | Neo Diamond | сторис |
| `[T·ib]` | taena | bio |
| `[T·is]` | taena | сторис |

Позже, если понадобится: `[N·ip]` / `[T·ip]` — пост или reels,
`[N·tb]` / `[T·tb]` — профиль TikTok.
