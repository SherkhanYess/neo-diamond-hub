# Конвертер заявки: автоопределение из amoCRM (решения на 2026-11-10)

Поле amoCRM «Источник лида» владелец переименует в **«Конвертер»**. Инфоцентр сам
заполняет его (и UTM, «ID объявления Meta») по первому сообщению — только пустые
поля, ручной выбор менеджера не перезаписывается.

## Решено
- **Нет `ad_id` → точно не конвертер «Реклама → WhatsApp»** (из рекламы сразу в чат),
  неважно, Kelesu это (Алматы) или Wazzup (Астана). Реклама при этом возможна через другой
  конвертер (реклама → сайт → WhatsApp) — это видно по коду сайта. Остальное — по тексту
  первого сообщения и коду в нём.
- **`ad_id` берём сами из текста.** Kelesu дописывает в сообщение, которое видит только
  amoCRM: `📢 Лид с рекламы` / ссылка на пост Instagram / `ad_id: 1202…`. Робот Kelesu,
  который сейчас заполняет поля 421871/422091, станет не нужен.
- **Каналы:** Kelesu = WhatsApp Алматы (и реклама CTWA), Wazzup = WhatsApp Астаны,
  `instagram_business` = Директ (канал виден по событиям amoCRM без текста).
- **Через REST API amoCRM текст переписки недоступен** (в событиях только id сообщения и
  канал). Текст в поле сделки — через Salesbot (проверяется) → синхронизация разбирает.
- Каталог neodiamond.kz, таплинк, конструктор, номер обращения — **пока не трогаем**.

## Захват текста — проверено 2026-11-11
- Salesbot «Инфоцентр: первое сообщение (тест)» (id 12535): шаг «Записать в сделку: Первое
  сообщение (424891): Сообщение клиента», «Оставлять непрочитанным» включено.
- Запуск — **«При первом входящем сообщении в любом источнике за день»**, не «при создании
  беседы»: беседы в аккаунте никогда не закрываются (все «в работе», у старых клиентов беседы
  годами открыты), и «создание беседы» поймало бы только новые контакты, а повторные
  обращения потерялись бы.
- Проверено на Kelesu, Wazzup и Директе: поле пишется за 2–5 с; каждая запись даёт событие
  `custom_field_424891_value_changed` (created_by 0, текст в `value_after`) — **история
  всех обращений читается через events API**, поле может перезаписываться.
- Инфоцентр: обращение = первое сообщение дня; повторное обращение = после ≥7 дней тишины
  (порог настраиваемый); конвертер сделки — по самому раннему тексту.
- Поле стоит переименовать в «Сообщение обращения» (владелец).

## Порядок работ (решение владельца)
1. **Сейчас:** аналитика конвертеров без рекламной связки — сайт, гид, профиль (bio/таплинк),
   Директ, 2ГИС, прямой WhatsApp — по тексту первого сообщения (Salesbot → поле
   «Первое сообщение» 424891 → синхронизация разбирает).
2. **Отдельная задача, позже:** связка «реклама → WhatsApp» (`ad_id` из сообщения Kelesu) —
   считается решённой текущим роботом, проработать отдельно.

## Сделано 2026-11-11: вебхук и разбор кода
- Вебхук amoCRM id 49125806 (update_lead, add_lead) → Edge Function `amocrm-hook`
  (?key=HOOK_KEY). Разбор — `supabase/functions/_shared/inquiry.js` (+ тесты).
- В поле остаётся только код: код сайта / профиля, `[ad·…]`, `[2ГИС]`, `[Директ]`,
  `[WhatsApp]`. Пустые UTM-поля сделки заполняются синтетическими метками, «Источник
  лида» — если пуст, тег `taena` — по коду бренда. Журнал — `crm_inquiries` (без текста).
- Миграция 0016: «Без источника» (WhatsApp, Сайт-каталог), «Рекомендации», TikTok →
  «Сайт-каталог». Директ без кода = конвертер «Профиль» (0017, решение владельца); `deals.demand_source_fixed` — «Рекомендации»
  (Рефералка / теги «сарафан…») не перебивается конвертером.
- 2ГИС: кнопка WhatsApp в карточках Neo Diamond (Алматы и Астана) подставляет
  «Здравствуйте! Пишу из приложения 2ГИС.» — правило «2гис/2gis» в тексте.
- ТЗ для сайта: `docs/tz/2026-11-11-taena-lead-code-v2.md`; ссылки профиля:
  `docs/tz/2026-11-11-profile-codes.md`. Сотрудник и TikTok пока не считаем.

## Было отложено (теперь — ТЗ выше): короткий UTM-код на сайте taena
Сайт хранит UTM входа; при переходе в WhatsApp превращает их в очень короткий код, чтобы
видеть не только «с сайта», но и откуда на сайт: bio / сторис / пост / реклама.
Черновик формата: `[ОБ·is·k3x9]` = тип обращения · площадка+размещение (2 буквы) · хвост.
- Реклама: хвост = ID объявления. Base36 даёт 11 символов — **владелец просит короче**:
  4–5 последних символов base36, однозначно сопоставляемых со списком объявлений из Meta.
- Органика: хвост = код ссылки; сайт при клике регистрирует «код → полные UTM» в инфоцентре.
- Начинать только по команде владельца.
